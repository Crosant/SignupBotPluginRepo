# SignupBot Dalamud plugin repository

Custom plugin repository for the [SignupBot](https://lfg.0xc4.net) in-game plugin.

## Install

1. In game, open `/xlsettings` → **Experimental**.
2. Under **Custom Plugin Repositories**, add:
   ```
   https://raw.githubusercontent.com/Crosant/SignupBotPluginRepo/master/repo.json
   ```
   Tick **Enabled**, then click the save icon.
3. Open `/xlplugins`, search for **SignupBot** and install it.
4. Run `/signupbot config` and paste your plugin token. On lfg.0xc4.net, open your name → Settings → In-game plugin (party leads and up).

This repo is updated automatically when a new plugin version is released; don't edit it by hand.
